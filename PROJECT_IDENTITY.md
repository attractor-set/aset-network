# ASET Network project identity

The project and repository are named **ASET Network**.

- Repository: `attractor-set/aset-network`
- Project package name: `aset-network`
- Rename scope: repository and project identity only
- Current project version: `0.1.0a4` (`0.1.0-alpha.4`)
- Semantic delta of promotion: **NONE**

The frozen alpha.3 canonical package and its assurance evidence were created under the historical **ASET Network Extension** identity. Their machine identifiers, document types, file paths, digests, and proof evidence are intentionally preserved unchanged. They remain exact predecessor evidence and regression material; they are no longer the current project representation.

A project rename does not grant semantic precedence, modify ASET Seed, or alter any Network transition, state field, invariant, conformance case, or proof claim.

## Alpha4 semantic evolution

`network/alpha4/**` is the current public Network representation. `network/CURRENT.aset` is a non-semantic project pointer that selects it without granting semantic precedence. It introduces paired operational and relational expressions for the same minimal admission subject and binds that subject content-addressedly to ASET Seed 0.4alpha. This is an explicit semantic evolution and does not rewrite the frozen Alpha3 package or its evidence.

`network/alpha4/profiles/**` carries the optional Dynamic, Federation and Liveness profile semantics for the current Alpha4 representation. The profiles remain separate from the core subject: Dynamic and Liveness add no Network state or transitions, Federation owns only its profile-local lifecycle, and profile composition transfers no Authority or parent relation. Every profile semantic object has an operational Forth expression paired with an independent TLA relational expression; property-only profiles use operational predicates rather than inventing profile-owned transitions. Operational expression is a representation of the semantic object, not a declaration of state or transition ownership: neither state nor transitions are prerequisites for a Forth expression.


## Promotion boundary

Promoting Alpha4 changes project identity and current-representation selection only. It does not change `network/alpha4/NETWORK.aset`, any Alpha4 Forth/TLA expression or proof, any profile semantic subject, either Seed binding, or any frozen Alpha3 artifact. `SEMANTIC-PRECEDENCE NONE` remains true for the current pointer, the Alpha4 subject and the profile registry.
