# Formal verification architecture

ASET Network Extension uses the same canon-first verification pattern as ASET Seed.
The machine-readable Network canon remains normative. TLA+ modules are assurance
artifacts and do not override the canon.

## Canon-to-model chain

```text
extension/canonical/source/network-extension-model.json
        |
        | deterministic generator
        v
NetworkCanonProjection.tla
        |
        | TLAPS behavioral-equivalence proof
        v
NetworkExtension.tla
        |
        +-- TLC safety
        +-- TLC conditional liveness
        +-- NetworkHistory.tla -> TLC history
        |
        | separate TLAPS refinement
        v
pinned SeedResolution.tla
```

`NetworkCanonProjection.tla` is generated by
`tools/generate_canon_tla_projection.py` under profile
`ASET-NETWORK-CANON-TLA-PROJECTION-V2`. It is standalone: it neither extends nor
instantiates `NetworkExtension`.

`NetworkCanonRefinementProofs.tla` explicitly instantiates the generated
projection onto the handwritten `NetworkExtension` state and proves the final
theorem:

`NetworkExtensionSafetyBehaviorallyEquivalentToCanonProjection`.

The current alpha.2 proof evidence records this relation as
`MECHANICALLY_PROVED`: pinned TLAPM commit
`4600b24c6d95a25ff081ad37b63b2a01c29d43a5` proved all 3 obligations for the
exact source model, generated projection, handwritten target and proof module
recorded in `extension/canonical/assurance/canon-refinement-proof.json`. The
obligation count is reproducibility evidence for this proof artifact, not a
fixed semantic contract.

This is intentionally parallel to Seed's standalone `SeedCanonProjection.tla`
plus `SeedCanonRefinementProofs.tla` construction.

## Claim boundary

The canon-to-TLA proof covers the declared finite-state safety projection. It
does not claim natural-language equivalence, wire-schema equivalence,
cryptographic correctness, transport implementation refinement, unbounded
liveness, evidence-history trace equivalence, or correctness of the projection
generator itself. The deterministic generator is part of the assurance trusted
computing base.

History and liveness remain separate surfaces because their semantics differ
from core transition safety:

- `NetworkHistory.tla` checks the bounded append-only evidence trace.
- `FairSpec` plus `NetworkExtensionLiveness.cfg` checks conditional liveness for
  the configured finite TLC model.
- `NetworkExtensionSeedRefinementProofs.tla` separately proves refinement to the
  exact pinned `SeedResolution.tla`.

## Reproducibility gates

Check that the committed generated projection is exact:

```text
python tools/generate_canon_tla_projection.py --check
```

Run the canon-to-handwritten TLAPS proof:

```text
python tools/run_canon_refinement_tlaps.py --tlapm <pinned-tlapm>
```

The aggregate release gate requires projection freshness, package validation,
conformance tests, unit tests, TLC safety/history/liveness, canon refinement
TLAPS, and the separate Network-to-Seed TLAPS refinement before it can emit
`FORMAL_RELEASE_GATE=PASS`.
