# Legal, IP, and provenance documents

Status: **non-normative project administration**.

Nothing in this directory changes the normative ASET Network Extension semantics,
its conformance requirements, or the meaning of the machine-readable canon.

This directory separates four concerns that must not be conflated:

1. copyright and authorship of the specification and assurance materials;
2. provenance and registration baselines for frozen releases;
3. trademark and naming rights for ASET identifiers and marks;
4. contribution rights for future third-party contributions.

Documents:

- `IP_RIGHTS_POLICY.md` — project-level rights boundary and licensing policy;
- `NETWORK_EXTENSION_REGISTRATION_BASELINE.md` — checklist for freezing a
  registration/deposit package for a material Network Extension release;
- `CONTRIBUTION_RIGHTS_POLICY.md` — rights rules for accepting future external
  contributions.

These documents are operational policy, not legal advice. Formal registration,
assignment, trademark filing, patent strategy, and contributor agreements should
be reviewed for the jurisdiction in which they are used.
