# Migration from the predecessor lifecycle canon

The active ASET Seed 0.2 resolution core intentionally removed federation topology and Context lifecycle. This repository reintroduces only the smallest federation-recognition subset as a separately versioned extension.

Historical concepts retained in narrowed form:

- Context as a normative namespace;
- ancestry does not imply Authority;
- Export -> local Import Observation -> local resolution -> local Outcome recognition;
- membership withdrawal requires dependency closure;
- federation and metafederation do not create superior sovereignty.

Not migrated into this alpha:

- partition-local transition classes;
- reconciliation from fork evidence;
- Context redefinition and transitive sibling consent;
- alias lifecycle;
- cryptographic and storage choices.

Historical predecessor material is evidence for provenance, not controlling canon for this extension.
